# なぜ?帳

街で見つけた違和感を「なぜ〜なのか?」の形で残すメモと、面白い記事を6つの欄で分解するメモ。

- ログインはいりません。記録は、使っている端末のブラウザの中にだけ保存されます(どこにも送りません)。
- 電波がなくても使えます。スマホでは「ホーム画面に追加」すると、アプリのように開けます。
- 記録は端末の中だけにあるので、ときどき「書き出し・保存」からバックアップを保存してください。

## メモの型

**問い(7欄)** タイトル/きっかけ/今の仮説/視点/データ・事例/自分の意見/今後のアクション

**記事の分解(6欄)** 要約/学び/自分ならどうするか/良かった点/問い/試したいこと

型は、杉浦圭さんの講義「1文字0.5円の記事を書いていた私が、ビジネス媒体で連載を持つまでにやったこと」(ライポタ)で紹介されたメモの欄をもとにしています。

## ファイル

- `index.html` アプリ本体
- `sw.js` 電波がなくても開けるようにする仕組み(画面を直したら、中の `VERSION` を上げる)
- `manifest.webmanifest`、`icon-*.png` ホーム画面に追加するときの名前とアイコン
